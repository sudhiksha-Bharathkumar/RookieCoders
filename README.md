# 🛡️ TrustSeal

### More Than a Seal. A Digital Witness.

**A smart, reusable tamper-evident system for food & e-commerce deliveries.**

</div>

---

## 🚨 Problem

Traditional seals can show visible damage, but they cannot reliably tell **when, how, or whether** a package was disturbed during transit. This creates a gap in customer trust and makes tampering disputes difficult to verify.

## 💡 Solution

**TrustSeal** combines multiple sensors to detect and correlate suspicious physical events, record them with timestamps, and maintain a verifiable digital history.

<center>

**Detect → Correlate → Record → Verify → Handover**

</center>

## ⚙️ Tech Stack

**Hardware:** ESP32 · LDR · Tamper Switch · MPU6050

**Software:** Python · Flask · HTML · CSS · JavaScript · SQLite

**Security:** SHA-256 Hash Chain · QR Verification

## 🔐 Key Features

- 🛡️ Multi-sensor tamper detection
- 📡 Real-time package monitoring
- 🕒 Timestamped event timeline
- 🔗 SHA-256 hash-linked event history
- 📱 QR-based receiver verification
- ♻️ Reusable hardware architecture

## 🚀 Future Scope

Offline storage · Better battery efficiency · Cloud deployment · Advanced anomaly detection · GPS · Temperature & environmental sensors
